# Privacy policy

*Applies to the `sdops` plugin (sheraf design ops). Last updated: 23 November 2026.*

## Summary

`sdops` is a set of instructions (skills) for Claude Code. It contains no code, runs no server and
has no service of its own, so the author of `sdops` never receives, sees or stores any of your data.

## What the plugin reads

When you use a skill, Claude reads, through the Figma connection **you** set up and authorise:

- the Figma files, libraries, screenshots and comments you point it to;
- the name of the signed-in Figma account, when you run the setup check;
- people's names that appear in those files (for example comment authors) or that you give it (for
  example the owner and approver of a pattern catalogue).

It also reads Markdown files in the folder you are working in, when you ask it to.

## What the plugin writes

Only what you approve, and only into your own files:

- changes and pages in the Figma files you name, after you approve the plan;
- Markdown files in the folder you are working in.

It never publishes a Figma library; publishing stays your action.

## Where data goes

- **Figma:** the official Figma MCP is a cloud service run by Figma; its use is covered by
  [Figma's privacy policy](https://www.figma.com/legal/privacy/). The optional Figma Desktop Bridge
  works locally on your computer.
- **Anthropic:** like any Claude Code session, the conversation is processed by Anthropic under your
  Claude plan's terms and [Anthropic's privacy policy](https://www.anthropic.com/legal/privacy).
- **Nowhere else.** The plugin sends nothing to any other service, and the author receives nothing.

## Retention

The plugin retains nothing. What it writes stays in your own Figma files and folders, under your
control. Undo any change from **File → Show version history** in Figma.

## Children

The plugin is meant for professional designers and is not intended for anyone under 18.
