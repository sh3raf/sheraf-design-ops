# Pattern vocabulary

Common names to start from. Prefer the catalogue's own name when it has one, and add these as aliases.

- **Interaction:** show / hide sensitive value, pull to refresh, swipe actions, long press to edit,
  inline validation, skeleton loading, empty state, undo, copy to clipboard, biometric confirm.
- **Navigation:** global navigation, side navigation, tabs, breadcrumbs, back navigation, bottom bar,
  command palette, pagination.
- **Input:** form, multi-step form (wizard), inline validation, autocomplete, date picker, file upload,
  inline edit, confirmation dialog.
- **Data display:** dashboard, data table, list with row actions, card grid, detail view, master-detail,
  charts with summary, comparison view.
- **Search and filter:** search with suggestions, faceted filters, saved views, sort, bulk selection
  and bulk actions.
- **Feedback:** toast, inline alert, banner, progress indicator, skeleton loading, empty state, error
  recovery, undo.
- **Onboarding:** first-run setup, guided tour, checklist, progressive disclosure, contextual help.
- **Account:** sign in, sign up, password reset, two-factor, profile and settings, permissions.
- **Commerce:** product listing, product detail, cart, checkout, payment, order status.
- **Content:** article, media gallery, comments, notifications centre, share.
